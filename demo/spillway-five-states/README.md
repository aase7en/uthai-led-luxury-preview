# UTH[AI] Spillway — Five animated states (isolated proof)

A visual-comparison demo using the **user-supplied reference image** as the art base.
Its HTML Canvas adds moving waterfall streaks, splashes, droplets, mist-like particles,
surface highlights and ripples for five *simulated* opening states:
0%, 25%, 50%, 75%, 100%. Buttons swap instantly and animation loops.
Includes pause/play, small-screen layout and reduced-motion support.

**NOT actual gate telemetry**: no sensor data, API calls, operational conditions,
or statements about current water level/risk. The dates/numbers inside the
photographic reference image are historical text baked into the user's picture.
Nothing here is connected to the real LED/public hospital display.

**Important quality boundary**: This is a reference-derived *Canvas look-dev POC*,
NOT Houdini/Blender FLIP water simulation or 5 approved pre-rendered cinematic loops.
High-quality production treatment should replace the Canvas layer with approved
per-state fluid/foam/mist rendered clips, keeping this five-state UX and art direction.

Source: image supplied by the user in ChatGPT on 2026-10-23. No redistribution outside
this separately hosted demonstration without user approval.
